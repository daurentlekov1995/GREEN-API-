# Тестовое задание для GREEN-API (DevOps разработчик)

Веб-страница для взаимодействия с методами GREEN-API. Проект выполнен на чистом HTML/CSS/JavaScript (Fetch API) без использования сторонних фреймворков и библиотек.

##  Ссылка на проект в Интернете
[Кликните сюда, чтобы открыть страницу](https://daurentlekov1995.github.io/GREEN-API/)

##  Реализованный функционал
На странице реализована интеграция со следующими методами GREEN-API:
* `getSettings` — получение настроек аккаунта.
* `getStateInstance` — проверка состояния инстанса.
* `sendMessage` — отправка текстового сообщения.
* `sendFileByUrl` — отправка файла (картинки/документа) по прямой ссылке.

##  Инструкция по запуску и проверке
1. Перейдите по ссылке на опубликованную страницу (или откройте `index.html` локально в браузере).
2. Введите ваши данные из личного кабинета GREEN-API: `idInstance` и `apiTokenInstance`.
3. Для проверки отправки сообщений введите номер телефона получателя в международном формате (например, `77771234567`) без знака `+`.
4. Нажимайте соответствующие кнопки методов. Ответ от серверов GREEN-API отобразится в правом поле "Ответ" в формате JSON.
